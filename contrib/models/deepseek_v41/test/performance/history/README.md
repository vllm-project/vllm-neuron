# Bench history: every `run_bench.py` run of this port

All runs on trn3.48xlarge (64 logical cores at LNC=2), checkpoint `/mnt/nvme/hf`, 128 output tokens,
medians. `max_num_seqs` is the engine's (`DEEPSEEK_V41_MAX_NUM_SEQS`; before 2026-10-24 every
engine above one rank was clamped to 1, and a `bs10` cell on such an engine queues its ten requests).
The top-level `bench_report*.json` files are the current reference per scheme; `history/reports/`
keeps the intermediate runs and `history/logs/` the console output of every run (its
summary table is at the end of each log). `cells/` holds the raw per-cell output of the last run
(the final `tp8pp8` runs: the `ms1` server logs and cells from r3_13, the `bs10` cells and the `ms10`
server logs from r3_14).

Per cell: TPOT p50 / decode tok/s / vLLM draft acceptance.
